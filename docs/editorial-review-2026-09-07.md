## 来源、素材及内部定义

- 2019 / 2020 / 2023 组织关系沿用 `content/ecosystem.ts` 中已核验的年度来源和角色数据，未重分类为当届名单。

- [西财新闻网：第七届赛事报道](https://news.swufe.edu.cn/info/1003/109791.htm)：本轮重新核对，支持 2024 年 10 月孵化器启动、20 余家参与单位、孵化与人才培养目的、两位颁奖者和张立生的视频邀请。没有将邀请变成下一届承办承诺。
- **20 余家**仅指 2024 年启动活动的参与机构，绝不代表当前会员、累计伙伴、孵化项目或公司数量。未增加后续经营成效或资金支持承诺。
- FIC 与伯克利 CDAR 保持不同机构身份；FIC 交流记录不改为成都八零赞助商记录。
- 既有 13 张历史照片、图片原始出处、空摄影师字段、授权门控、宽高和 WebP 资产不变。唯一图注例外见 `docs/media-authorization.md`。

- `npm run typecheck`、`npm run lint`、`npm test`：54 项通过；`npm run build`、`node scripts/check-public-ui.mjs`、`git diff --check` 通过。
- 浏览器：本机 macOS，Chrome 152.0.7977.76，隔离的 Playwright 无登录环境。
