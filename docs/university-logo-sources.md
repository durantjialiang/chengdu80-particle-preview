# University logo sources

Updated 2026-09-17. Local files are original university assets, not redrawn marks. At the project owner's request, mainland universities are now shown by name only. Their standalone logo files have been removed from the public assets and all shared university records use `logo: null` for those institutions. The owner explicitly asked to retain the University of Hong Kong logo alongside the 12 foreign university logos.

| Record | Local asset | Official source | Surface |

| UC San Diego | `/university-logos/ucsd.svg` | https://brand.ucsd.edu/logos/primary-campus-logo/index.html — uc-san-diego-logo-kit-042425.zip | Light: original blue/gold mark |

| Berkeley | `/university-logos/uc-berkeley.png` | https://brand.berkeley.edu/wp-content/uploads/2024/08/logo-variations-thumbnail-gold-blue-1.png | Original blue canvas with gold wordmark; CSS fills the tile without clipping the wordmark |

All other retained marks have their existing official source in `content/universities.ts`. The shared logo tile preserves image aspect ratio. Chicago's supplied artwork includes additional clear space, compensated within the tile with a modest CSS scale. Berkeley retains its original source pixels and colors; CSS reduces the outer blue canvas while preserving the full centered mark and clear space. Tel Aviv's black mark uses a light surface. No artwork is recolored. University roles and academic exchanges remain dated historical records, not a confirmed 2026 roster.
